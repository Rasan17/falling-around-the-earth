# Falling Around the Earth

Interactive models and animations showing:

1. How a rocket's trajectory changes from launch until the module enters orbit with a sideways velocity.
2. How that sideways velocity keeps the module in orbit, and what happens if it is too slow (crash), faster (higher, stretched orbit) or much faster (escape).
3. How cerebrospinal fluid (CSF) pressure and volume in the head change from standing on Earth, through launch, to weeks and months in orbit (spaceflight-associated neuro-ocular syndrome, SANS).

Open `index.html` in a browser, or view it online via GitHub Pages.
